# 💍 קולולו – רשימת מוזמנים והושבה לחתונה

אפליקציה בעברית לזוג שמתחתן: רשימת המוזמנים, אישורי הגעה, וסידור השולחנות.
אותו מראה, צלילים ואנרגיה של Cybertron3 – רק בצבעי חתונה (זהב, ורוד ולבן).

## איך זה עובד

- **כניסה** עם תעודת זהות (או כל קוד אישי, לפחות 4 תווים). תעודת זהות נבדקת שהיא תקינה.
- כל קוד פותח **רק את החתונה שלו**. אם אין עדיין חתונה לקוד – האפליקציה מציעה לפתוח אחת (שם החתן, שם הכלה, תאריך).
- **מוזמנים**: שם, טלפון, צד (חתן / כלה / משותף), קשר, קבוצה, כמה מקומות, ילדים, אישור הגעה, גיל, אוכל, איפה נוח לשבת, נגישות, אורח חשוב, "לא להושיב ליד", הערות.
- לחיצה על ⏳ מחליפה אישור הגעה: מגיע ✅ → אולי 🤔 → לא מגיע ❌.
- 📞 מתקשר, 💬 פותח וואטסאפ עם הזמנה מוכנה.
- **הושבה**: "✨ הושבה אוטומטית" מסדרת לפי קבוצה, צד, קשר, גיל, אזור באולם ו"לא להושיב ליד". אחר כך מתקנים ביד: לוחצים על מוזמן ואז על שולחן (במחשב אפשר גם לגרור).
- **פרסומות** מתחלפות למטה, מתוך `adv.json` (כמו ב-Tsgreen3).

## שמירה

- כל שינוי נשמר **לבד, באינטרנט** (Firebase), תוך שנייה. למעלה רואים: ⏳ שומר... / ☁️ נשמר / 📴 נשמר בטלפון.
- כל זוג = קובץ JSON אחד, **נעול** עם הקוד שלו. גם בעל האתר לא יכול לקרוא אותו.
- אין אינטרנט? השינויים נשמרים בטלפון ועולים לבד כשהחיבור חוזר.
- הזוג לא צריך לדעת על GitHub או על קבצים. נכנסים מכל טלפון עם אותה תעודת זהות – והרשימה שם.
- "⬇️ הורדת קובץ" בהגדרות = גיבוי שנשאר אצלכם.
- ההגדרות של Firebase נמצאות ב-`firebase-config.js`. חוקי האבטחה ב-`firestore.rules` (מדביקים ב-Firebase → Firestore → Rules).
- רק מי שיודע את הקוד יכול לפתוח את הקובץ. בכל זאת: אם רוצים להיות בטוחים במיוחד – עדיף קוד אישי ארוך במקום תעודת זהות.

## לנסות

- פותחים את `start.cmd` (צריך Python), או נכנסים לאתר ב-GitHub Pages.
- חתונה לדוגמה: תעודת זהות **123456782** (איתי ונועה, 19 מוזמנים).
- פתיחה ישירה של `index.html` מהתיקייה לא תעבוד – צריך שרת (start.cmd) או את האתר.
